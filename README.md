# Hack The Box Notes

Personal notes and practical documentation from my journey through Hack The Box.

## About

This repository contains my notes, key concepts, practical techniques, and lab experience while progressing through Hack The Box Academy and Machines.

The goal is not only to complete the content, but to understand how vulnerabilities work, how they can be identified and exploited, and how to approach them from a penetration tester's perspective.
