# CPTS Job Role Path

This directory contains my notes from the **Hack The Box Academy Certified Penetration Testing Specialist (CPTS) Job Role Path**.

The content is organized following the official path structure, with each module containing my personal notes, commands, explanations, lab solutions, and key concepts covered throughout the course.

The purpose of these notes is to document my learning progress, reinforce my understanding of each topic, and serve as a reference while preparing for the **CPTS** certification.
