# Getting Help

## Overview

Getting stuck is a normal part of working through boxes and modules. HTB provides community resources for getting (and giving) help without resorting to spoilers — knowing how to use them well, and how to ask questions effectively, makes the difference between a quick nudge and an unhelpful wall of silence.

## Learning Objectives

- Know when and how to use the HTB Forum and Discord
- Ask for help effectively without requesting spoilers
- Answer others' questions helpfully while staying spoiler-free
- Know where to go for technical/platform issues

## HTB Forum

The HTB Forum (forum.hackthebox.com) hosts an official, spoiler-free discussion thread for every box. These threads are a good first stop for retired boxes when stuck — reading existing hints and tips in the thread often resolves an issue without needing a full walkthrough.

## HTB Discord

The HTB Discord covers announcements, box/challenge discussion, Academy module discussion, general lab support, and broader hacking/pentesting conversation. House rule: no trolling, and keep all content SFW.

## Asking Questions Effectively

A good help request states, clearly and specifically:

1. **Where exactly you're stuck** — user access, root/privesc, a specific step, etc.
2. **What steps you've already taken** — so people don't repeat suggestions already tried.
3. **Exactly what's failing**, and what's already been attempted to fix it.

Being specific rather than vague ("it's not working") gets dramatically better responses. Never give — or ask for — spoilers.

## Answering Questions Effectively

When helping someone else: stay spoiler-free, offer minor hints or nudges in the right direction rather than the full solution, share genuinely helpful resources, and don't hesitate to mention your own past sticking points on the same box — it normalizes getting stuck and often points directly at the fix.

## Technical Issues and Support

For platform/technical issues (not box-related), check the official HTB FAQ first. If that doesn't resolve it, raise a support ticket — and disable adblockers first, since they can hide the support chat bubble entirely.

## Skills Practiced

- Using community resources (Forum, Discord) effectively and appropriately
- Writing clear, actionable help requests
- Giving spoiler-free guidance to others

## Key Takeaways

- A specific help request (stuck point + steps taken + exact failure) gets better answers faster than a vague "it's not working."
- Spoiler-free box threads exist specifically so stuck users can get unstuck without anyone having to post (or receive) a full solution.
- Disabling adblockers before raising a support ticket is a small, easily-missed step that avoids an invisible support chat.
