# Next Steps

## Overview

A roadmap for progressing after finishing the Getting Started module — from rooting a first guided retired box all the way to a fully independent Active box, plus habits (continued learning, giving back) that keep that progress compounding.

## Learning Objectives

- Understand the suggested progression from guided to fully independent boxes
- Identify how to keep learning beyond boxes alone
- Understand ways to give back to the community
- Use the way-forward checklist to track overall progress

## Suggested Progression

1. **Root a retired Easy box** using the official VIP walkthrough. Tip: watch a video walkthrough once in full, then try to replicate it independently without following along step-by-step — refer back only when actually stuck.
2. **Complete a retired Medium box** — these typically demand more knowledge and persistence than Easy boxes.
3. **Root a first live/Active box** after accumulating roughly 5–10 retired Easy/Medium boxes. Pick something Easy, difficulty 1–3/10, since no walkthrough is available this time — only community help channels. This is often described as the hardest "first," precisely because there's no safety net.

## Keep Learning

Boxes alone will leave knowledge gaps. Supplement hands-on practice with more Academy modules in whatever areas feel weakest, and keep a running to-do list of modules worth coming back to.

## Giving Back

Once a box has been completed independently, two good ways to reinforce that knowledge while helping others:

- Answer other people's questions in the help channels.
- Write up and publish a full walkthrough of a retired box. Tip: draft the writeup while the box is still active/live, and publish it once the box officially retires.

## Way-Forward Checklist

- [ ] Root a retired Easy box
- [ ] Root a retired Medium box
- [ ] Root an Active box
- [ ] Complete an Easy challenge
- [ ] Share a walkthrough
- [ ] Complete more Academy modules
- [ ] Root live Medium/Hard boxes
- [ ] Complete a Track
- [ ] Win a Battlegrounds match
- [ ] Complete a Pro Lab

## Skills Practiced

- Structuring a long-term, self-directed learning plan
- Writeup/documentation habits for later reference and community contribution

## Key Takeaways

- The jump from "walkthrough available" to "no walkthrough, community help only" on a first Active box is intentionally the biggest step in this progression — it's meant to feel harder.
- Drafting a box writeup while it's still live (rather than after retirement) captures details that are easy to forget later.
- A running to-do list of Academy modules keeps gaps from boxes-only practice from going unaddressed indefinitely.
