# Starting Out

## Overview

Beyond HTB Academy's structured modules, Hack The Box offers an exploratory learning path through its main platform — challenges, machines, Endgames, Fortresses, and Pro Labs. Knowing what resources exist outside a single module helps plan a sustainable, well-rounded learning path.

## Learning Objectives

- Differentiate guided learning from exploratory learning and know when to use each
- Identify practice resources outside of HTB Academy
- Understand HTB Starting Point and Tracks as beginner-friendly on-ramps
- Identify beginner-friendly machines, challenges, and Pro Labs

## Guided vs. Exploratory Learning

- **Guided learning (HTB Academy):** structured modules with built-in exercises and skills assessments — a clear, scaffolded path from topic to topic.
- **Exploratory learning (main HTB platform):** challenges, machines, Endgames, Fortresses, and Pro Labs — a black-box approach with no hand-holding.

Mixing both styles tends to work best: Academy builds the foundational knowledge, and the main platform forces that knowledge to be applied without a script to follow.

## Practice Resources

**Vulnerable machines/apps to practice locally** (no VPN needed):

- OWASP Juice Shop
- Metasploitable 2/3
- DVWA (Damn Vulnerable Web Application)

**YouTube channels:**

- IppSec — in-depth retired HTB box walkthroughs
- VbScrub — Active Directory focus
- STÖK — bug bounties and web pentesting
- LiveOverflow — broad infosec topics

**Blogs:**

- 0xdf hacks stuff — retired HTB walkthroughs, notable for their "Beyond Root" sections that go past the intended solution

**Tutorial/war-game sites:**

- OverTheWire / UnderTheWire — "war games" format for practicing Linux/Windows command line and scripting fundamentals

## HTB Starting Point and Tracks

**Starting Point** is a guided introductory tutorial covering VPN connection, enumeration, foothold, and privilege escalation, plus several easy machines — designed as a gate before diving into the rest of the platform.

**Tracks** are curated sequences of machines and challenges built around mastering one specific subject.

## Beginner-Friendly Machines and Challenges

- **Machines:** Lame, Blue, Nibbles, Shocker, Jerry
- **Challenges:** Find The Easy Pass, Weak RSA, You know 0xDiablos

## Pro Labs for Beginners

**Dante** is the most beginner-friendly Pro Lab — a simulated enterprise network that bridges the gap between single-machine exercises and a full internal pentest engagement.

## Skills Practiced

- Mapping out a personal learning plan across guided and exploratory resources
- Identifying appropriately-leveled practice targets

## Key Takeaways

- Academy modules teach concepts; the main platform's black-box machines and challenges test whether those concepts can actually be applied without guidance.
- Local vulnerable apps (Juice Shop, Metasploitable, DVWA) are a zero-cost way to practice before spending lab time on the VPN.
- Starting Point and curated Tracks exist specifically so a beginner doesn't have to guess which box to try next.
