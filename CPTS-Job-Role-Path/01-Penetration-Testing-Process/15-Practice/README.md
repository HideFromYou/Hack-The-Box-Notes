# Practice

## Overview

Closes the module by emphasizing that theory alone is insufficient — hands-on repetition plus strong written/verbal communication skills are what actually build competence and confidence — and lays out concrete practice blueprints for modules, retired machines, active machines, and Pro Labs/Endgames.

## Learning Objectives

- Understand why soft skills (writing, presenting, defending findings) are treated as core skills, not optional extras
- Apply the module, retired-machine, active-machine, and Pro Lab practice blueprints
- Build a sustainable practice regimen appropriate to skill level

## Practicing Soft Skills

Rehearsing kickoff calls and report-review meetings with teammates playing the "client" role — practicing scoping questions, defending recommendations under pushback, etc. — builds a noticeably more polished, professional delivery.

## Documentation Quality Matters as Much as Findings

A vague 2-page report undermines credibility regardless of how impressive the actual compromise was. Conversely, a long but poorly organized or unclear report is equally unhelpful. Documentation & Reporting (a separate module) covers this in depth.

## Suggested Practice Regimen

Concrete starting numbers, adjustable based on personal interest and skill gaps:

- 2x modules
- 3x retired machines
- 5x active machines
- 1x Pro Lab/Endgame

## Module Practice Blueprint (7 steps)

1. Read the module
2. Practice the exercises
3. Complete the module
4. Redo the module's exercises from scratch
5. Take notes while redoing them
6. Create technical documentation from those notes
7. Create non-technical documentation from those notes

## Retired Machine Practice Blueprint (8 steps)

1. Get user flag solo
2. Get root flag solo
3. Write technical documentation
4. Write non-technical documentation
5. Compare your notes against the official/community write-up
6. List what you missed
7. Watch IppSec's walkthrough and compare again
8. Expand your notes/documentation with the missed parts

A VIP subscription gives access to official HTB write-ups, which often include defensive/blue-team considerations too.

## Active Machine Practice Blueprint (4 steps)

Blackbox, no official write-up yet since the machine is live:

1. Get user + root flags
2. Write technical documentation
3. Write non-technical documentation
4. Have both proofread by a technical person and a non-technical person — gives real feedback on whether the writing actually lands with each audience

## Pro Lab/Endgame Practice

Once comfortable with single hosts, move to large multi-host simulated-enterprise environments. The focus shifts to documenting an entire attack chain across interconnected hosts, not just a single box start-to-finish — closer to real engagement conditions (e.g., intercepting credentials with Responder becomes much more realistic in a multi-host AD environment than against a single isolated box).

## Closing Guidance

Follow the module order for the full path if just starting, since concepts build on each other. If partway through the path already, it's worth revisiting completed modules through the lens of this process model. Continuous practice and improvement is essential given how fast TTPs evolve in the field.

## Skills Practiced

- Structuring practice around repeatable blueprints (module, retired machine, active machine, Pro Lab)
- Producing both technical and non-technical documentation for the same finding
- Comparing personal write-ups against official/community write-ups to find gaps

## Key Takeaways

- Writing two versions of documentation (technical and non-technical) for every target, from the start, builds the communication skill that real engagements actually require — it's not a late-stage add-on.
- Comparing your own write-up against the official one and listing exactly what was missed is what turns repetition into improvement — redoing the same steps without that comparison doesn't build new skill.
- Pro Labs/Endgames exist to practice documenting an attack chain across many hosts, not just solving boxes — that's the skill a real internal pentest actually demands.
